## 8. Known Limitations
- **Replay**: The deployed QCG replay lineage endpoint (`/qcg/replay/lineage/{trace_id}`) returns 404. The current `PlatformReplayAdapter` is missing the `submit()` method required by the integration workflow. The existing replay evidence was generated by the local stub `CanonicalReplayAuthority`, not the canonical QCG replay authority.
- **Telemetry**: `TraceStore` is imported unconditionally from `src/platform/stubs.py`. No live telemetry backend is configured or reachable. Telemetry evidence represents local stub return values, not live exports.
- **Manifest Forwarding**: The deployed Platform HTTP registration handler does not currently forward a manifest into the underlying registry registration call. The `manifest` field can be null in metadata. This is a Platform-side limitation but does not block registration, discovery, negotiation, or invocation.

## 9. Platform Dependencies
